# Trigglow Studios

**Trigglow** builds live streaming software, interactive broadcast overlays, real-time analytics, and native OBS Studio integrations for creators across Twitch, YouTube, Kick, and TikTok.

### Public & Open-Source Projects
- **[Trigglow Studio](https://github.com/TrigglowStudios/TrigglowStudio)** — Desktop companion app for Windows and Linux with built-in `libobs` scene editing, instant clip capture & GPU compression, live game integrations (League of Legends & CS2), one-click OBS docks, and song requests.
- **[Trigglow Dynamic Delay](https://github.com/TrigglowStudios/trigglow-dynamic-delay)** — Native C/C++20 OBS Studio plugin (`v30+`) providing smooth canvas and stream delay transitions (0.5x catch-up & 2.0x catch-back) with zero stream cuts, Stream Deck integration, and built-in media relay.

🌐 **Website:** [trigglow.com](https://trigglow.com)


# Trigglow Studios

**Trigglow** desarrolla software para streaming en directo, overlays interactivos, analíticas en tiempo real e integraciones nativas con OBS Studio para creadores en Twitch, YouTube, Kick y TikTok.

### Proyectos públicos y Open Source
- **[Trigglow Studio](https://github.com/TrigglowStudios/TrigglowStudio)** — Aplicación de escritorio para Windows y Linux con editor de escenas basado en `libobs`, captura de clips al instante con compresión por GPU, integraciones de partidas en vivo (League of Legends y CS2), docks de OBS en un clic y peticiones musicales.
- **[Trigglow Dynamic Delay](https://github.com/TrigglowStudios/trigglow-dynamic-delay)** — Plugin nativo en C/C++20 para OBS Studio (`v30+`) con transiciones progresivas de delay en lienzo y en stream (0.5x y 2.0x) sin cortar la emisión, integración con Stream Deck y relay multimedia integrado.

🌐 **Web:** [trigglow.com](https://trigglow.com)
